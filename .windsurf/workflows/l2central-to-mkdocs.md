# l2central-to-mkdocs

Конвертация HTML-страницы с l2central.local в сегментированные Markdown-файлы для MKDocs.

## Шаг 1: Сбор входных данных

Перед началом работы агент **обязательно** должен спросить у пользователя:

1. **URL страницы l2central** — какую страницу преобразовать (например, `http://l2central.local/lineage/info/hf5/High_Five%2C_%D1%87%D0%B0%D1%81%D1%82%D1%8C_2.html`)
2. **Путь для иконок** — куда складывать иконки и какой label использовать (например, `![ct26p2](../../assets/images/chronicles/ct2_6p2/icon/{имя иконки})`)
3. **Путь для больших картинок** — куда складывать картинки большего размера (например, `![ct26p2](../../assets/images/chronicles/ct2_6p2/{имя картинки})`)
4. **Директория результата** — куда положить итоговые Markdown-файлы (например, `docs\Game_Updates\CT2.6_-_HighFive_part2`)
5. **Список файлов и заголовков** — какие файлы уже созданы в директории результата и какие h1/h2 заголовки в них содержатся. Если файлы уже есть с заголовками, скрипт должен сохранять эти заголовки и добавлять контент после них.

## Шаг 2: Загрузка HTML

Использовать инструмент `mcp0_fetch` для загрузки HTML-страницы:
- URL: указанный пользователем
- `max_length`: `999999` (не `1000000` — вызывает ошибку валидации)
- `raw`: `false`

Сохранить результат во временный файл.

## Шаг 3: Анализ структуры HTML

- Основной контент находится в `<div id="mw-content-text">`
- Контент сегментирован по `<h1>` — каждая секция h1 соответствует отдельному Markdown-файлу
- Внутри секций могут быть `<h2>`, `<h3>` — подзаголовки
- Таблицы могут содержать `rowspan`/`colspan`
- Картинки обёрнуты в `<a class="image"><img ...></a>` или просто `<img>`
- Иконки обычно `width="32" height="32"`, большие картинки — больше
- Предметы и умения обёрнуты в `<span class="item">` или `<span class="skill">` с вложенными `<span class="i_icon">` и `<span class="i_name">`

## Шаг 4: Создание Python-скрипта конвертации

Скрипт должен:

### Фильтрация мусора
Пропускать элементы с классами: `relpage`, `attention`, `printfooter`, `catlinks`, `toc`, `suckerfish`, `todo`, `gf-menu`, `visualClear`
Пропускать элементы с id: `toc`, `catlinks`

### Конвертация картинок
- Если `width <= 32` — иконка, использовать путь для иконок
- Иначе — большая картинка, использовать путь для больших картинок
- Имя файла: `urllib.parse.unquote(src)` → `basename` (с заменой `\` на `/`)
- Если `src` пустой или `#`, использовать `alt` с заменой пробелов на `_`

### Конвертация span.item / span.skill
- `span.i_icon` → извлечь `<img>` → конвертировать в markdown-картинку
- `span.i_name` → извлечь текст ссылки → обернуть в `**название**`
- Результат: `![label](путь/иконка) **Название предмета**`

### Конвертация таблиц
- Первая строка с `<th>` — заголовок
- Остальные строки — данные
- Каждая ячейка конвертируется через `convert_inline` (обработка вложенных тегов)
- `<br>` внутри ячеек заменять на ` <br> `
- Таблицу оборачивать в `<div class="compact-table noborder-table-b" markdown>\n\n{table}\n\n</div>`

### Конвертация списков
- `<ul>` → `- item` с отступами для вложенных
- `<ol>` → `1. item`
- Вложенные списки обрабатывать рекурсивно с увеличением отступа

### Конвертация inline
- `<b>`, `<strong>` → `**text**`
- `<i>`, `<em>` → `*text*`
- `<br>` → ` <br> `
- `<a class="image">` с вложенным `<img>` → конвертировать картинку
- `<a>` без картинки → просто текст
- `<font>` → просто текст (цвет игнорировать)

### Сегментация по h1
- Каждый `<h1>` начинает новую секцию
- Имя секции = текст h1
- Секция маппится на файл из списка пользователя
- Если для секции нет маппинга — вывести предупреждение

### Сохранение заголовков
- Если файл уже существует, прочитать его и сохранить все строки начинающиеся с `#`
- Новый контент добавлять после существующих заголовков

## Шаг 5: Запуск скрипта

```powershell
python "путь/к/скрипту.py"
```

Запускать из корня MKDocs проекта.

## Шаг 6: Проверка результата

После выполнения скрипта:
1. Прочитать все сгенерированные файлы
2. Проверить:
   - Нет дублированных заголовков
   - Нет навигационного мусора (ссылки на другие хроники, категории и т.п.)
   - Картинки используют правильные пути (из Шага 1)
   - Таблицы обёрнуты в `<div class="compact-table noborder-table-b" markdown>`
   - Списки правильно вложены
   - Все секции h1 попали в правильные файлы
3. Если есть проблемы — исправить вручную или доработать скрипт и перезапустить

## Шаг 7: Очистка

Удалить временный Python-скрипт после успешной конвертации.

