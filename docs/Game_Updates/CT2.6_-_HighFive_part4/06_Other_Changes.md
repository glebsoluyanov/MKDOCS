# Другие изменения
## Остров Грез

- По прибытии на Остров Грез персонаж получает положительный эффект:
    - увеличивает скорость и уменьшает повреждения при падении персонажа
- На Остров Грез добавлен НПЦ Хранитель Склада
- Добавлен НПЦ для более удобного перемещения по острову
- Добавлены новые товары и услуги за Монеты Острова Грез
- Добавлен новый НПЦ, который поможет сделать отличные скриншоты.

## Гильдия Путешественников

- Покупка предметов - раньше для покупки надо было нажимать специальный линк, теперь добавлен удобный интерфейс
- Вспомогательная магия (только для слуг) - раньше накладывались сразу все эффекты, теперь можно выбирать нужные.
