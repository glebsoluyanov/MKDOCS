## Прочие изменения предметов

- Для облегчения дифференциации изменены иконки Забытых Свитков
    - Для рыцарей - иконка с щитом
    - Для воителей - иконка со скрещенными мечами
    - Для магов и целителей - иконка магическим свитком
- При использовании предметов со свойствами Поддержания или Зарядки энергии соответствующий эффект срабатывает моментально.
- ![ct26p3](../../assets/images/chronicles/ct2_6p3/icon/Ожерелье_Фреи.jpg) **Ожерелье Фреи**, ![ct26p3](../../assets/images/chronicles/ct2_6p3/icon/Благословенное_Ожерелье_Фреи.jpg) **Благословенное Ожерелье Фреи** исправлена иконка пассивного умения.
- Исправлена невозможность улучшить среднее и лучшее оружие S84 Камнями Жизни 46-55 уровней.
- ![ct26p3](../../assets/images/chronicles/ct2_6p3/icon/Оскал_Венеры.jpg) **Оскал Венеры** исправлен описание для PvP версии оружия с СА Ускорение
- Для эльфов мужчин исправлена проблема отображения ![ct26p3](../../assets/images/chronicles/ct2_6p3/icon/Рука_Икара.jpg) **Рука Икара** при экипированных ![ct26p3](../../assets/images/chronicles/ct2_6p3/icon/Рукавицы_Дестино.jpg) **Рукавицы Дестино**
