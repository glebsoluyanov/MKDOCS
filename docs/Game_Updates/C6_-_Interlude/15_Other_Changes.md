# Other Changes

- *Windows 98* is no longer officially supported.
- Fortresses have been added. These fortresses will play a part in later updates of The Chaotic Throne.
- Replays created in Chronicle 5 cannot be viewed in Interlude.
- A new newbie buff, the Blessing of Protection, has been added.
- The Coliseum's arena is now an ordinary field. Unrestricted PvP is no longer permitted in the Coliseum, so please use the other arenas.
- The system message window option has moved from the Options window to the chatting option window.
- The food consumption amount for an ordinary pet has been decreased.
- Doors that cannot be destroyed, such as the castle gate and the clan hall gate, are indicated as "door" in the target window, and their HP do not appear.
- Some general, Noblesse, and clan hall teleport destination coordinates have been moved to a safer location.
- The problem with the Pagan Temple's Dungeon Gatekeeper NPC not responding normally to a player without a mark has been corrected.
- After the count for the Olympiad games begins, CP, HP, and MP are restored once more.
- Olympiad points will be deducted if the character is recalled to the stadium while that character is teleporting. The opponent's points will not be affected.
- The requirements for becoming a Hero from a Hero waiting state have been changed as follows:
  - Only a main class (not a subclass) can become a Hero.
  - Only a main class above level 75 can become a Hero.
- An issue with the Wyvern Breath skill has been corrected.
- The effect of the Christmas tree is no longer available in peace zones.

## Renamed Skills and Servitors

- Summon Queen the Cat is now called Summon Feline Queen.
- Summon Unicorn Boxer is now called Summon Boxer the Unicorn.
- Summon Unicorn Merrow is now called Summon Merrow the Unicorn.
- Summon Unicorn Mirage is now called Summon Mirage the Unicorn.
- Shield of Pa'agrio is now called Under the Protection of Pa'agrio.
- Stun Shot is now called Stunning Shot.
- Force Buster is now called Force Burst.

Various text corrections have been made.
