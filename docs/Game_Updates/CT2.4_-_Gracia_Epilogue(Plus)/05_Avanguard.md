# Усиление трансформации "Авангард"
Для упрощения одиночной игры рыцарским классам, была усилена трансформация "Авангард". Добавлены новые умения.

<div class="compact-table noborder-table-f tw100" markdown>

| Название | Описание |
| --- | --- |
| ![icon](../../assets/images/chronicles/ct2_4/icon/Духовность.jpg) Духовность | Увеличивает Точность Атак на 8, Вероятность нанесения Крит. Атк. + 150, Крит. Атк. + 30%. Требуются меч, дубина или парные мечи. |
| ![icon](../../assets/images/chronicles/ct2_4/icon/Гильотина.jpg) Гильотина | Наносит противнику дополнительный урон. Возможно использование с мечами и дубинами. Игнорирует блоки щитом. Сверхудар. |
| ![icon](../../assets/images/chronicles/ct2_4/icon/Тройной_Удар_Клинком.jpg) Тройной Удар Клинком | Увеличивает Мощность Атаки. Для использования требуются парные мечи. Игнорирует щит. Возможен сверхудар. |

</div>
