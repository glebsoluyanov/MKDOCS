# Поиск Командного Канала
Добавлена система Поиска Командного Канала для облегчения поиска игроков для вступления в Командный Канал.

- Поиск Командного Канала создается, когда лидер Командного Канала открывает окно поиска группы (/partymatching), и прекращается, когда лидер Командного Канала закрывает это окно.

## Правила поиска Командного Канала
- Лидер группы, создавший комнату поиска Командного Канала, не может находиться в состоянии поиска группы или создать комнату поиска группы.
- Интерфейс поиска Командного Канала идентичен интерфейсу Поиска Группы.
- Когда Вы входите в комнату поиска Командного Канала, Вы удаляетесь из поиска группы и не можете быть приглашены через систему Поиска Группы.
- Обычные члены группы не могут войти в комнату поиска Командного Канала, только лидер группы.
- Игроки входящие в комнату поиска Командного канала автоматически выкидываются из нее если они присоединяются к Командному Каналу или другой группе.
