# Квесты
Были добавлены новые квесты, включая квесты для Зон Охоты подвергшихся изменениям. Существующие квесты , которые раньше выполнялись в этих зонах были изменены. Были добавлены повторяемые квесты, которые можно выполнять только 1 раз в день.

Добавлена эпическая серия, содержащая 7 квестов позволяющих раскрыть тайны 7 печатей. Начать серию квестов можно на 79 уровне у Начальника Склада Крупа в Орене.За выполнение серии квеств вы получите большое количество опыта и SP, Древнюю Адену и уникальные предметы.

## Изменения в существующих квестах
- Исследование Пещеры Гигантов, ч. 1, Исследование Пещеры Гигантов, ч. 2, Час Икс, Призраки Батура и Признаки восстания изменены, ранее взятые квесты закончить невозможно, награду можно получить у NPC Лента Новостей в каждом городе.* По сообщениям квесты можно завершить у стартового НПЦ, можно ли их продолжить, непонятно.
- Королева Суккубов для квесты Испытание храбрости теперь водится внутри Заброшенного Угольного Рудника.
- Аудиенция у Дракона Земли - Медведь Зомби и Паук Зомби для квесты теперь водятся на Забытых Равнинах.
- Самонадеянный поиск - изменен предмет, необходимый для 1 части квест вместо Камня Мощи Гиганта будет необходим Панцирь Демона, его можно будет добыть убивая Око Хаоса и Палиотов на Забытых Равнинах.
- Амбиции Клана - вместо Камня Мощи Гиганта и Кристалла Небулита будет необходима Энергия Мстительного Духа, которую можно добыть убивая Главарей Злобных Душ на Поле Брани.
- Репутация Клана - Хекатон Прайм исключен из списка Рейд-Боссов, подходящих для повышения уровня. Вместо него подходит Рейд-Босс Хисилром Жрец Шилен.
- Престиж Клана - Королева Стакато Шиид больше не подходит для прохождения квеста.
- Сумрачный Лис - 2 - монстры, необходимые по квесту теперь водятся на Пляже Аллигаторов.
- Воскрешение мертвых - монстры, необходимые для квеста, теперь водятся на Пляже Аллигаторов.
- Черный Лебедь - монстры, необходимые для квеста, теперь водятся на Пляже Аллигаторов.
- Новый питомец - монстры, необходимые для квеста, теперь водятся вокруг Хейна.
- Свадебный марш - монстры, необходимые для квеста, теперь водятся вокруг Хейна.
- В поисках гнезда - уровень для начала квеста изменен с 66 на 81, увеличена награда.
- Поплавки для рыбалки - ![icon](../../assets/images/chronicles/ct2_4/icon/Сладкая_Жидкость.jpg) Сладкая Жидкость нельзя добыть в зонах, подвергшихся изменениям.
- Охота на динозавров, Расцвет и упадок племени Элроки - в награды добавлены рецепты брони и оружия Династии (S80).
- Горящие факелы - монстры, необходимые для квеста были скорректированы, шанс выпадения факелов повышен.
- На защиту Зала Гибели!, Захват Зала Гибели - уровень для начала квсета понижен до 75.
- Состояние маяка - уровень для начала квеста изменен с 40 на 80, увеличена награда.
- Усиление оружия — Теперь можно улучшать Кристалл Души до 14 уровня при охоте на Рейд-Боссов Хекатон Прайм, Королева Шипастых Стакато Шиид, Аэнкинель.
