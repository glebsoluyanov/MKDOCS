# Прочие изменения

## Лента Новостей

![ct25p1](../../assets/images/chronicles/ct2_5p1/HF_-_Лента_Новостей.jpg)

Как и в предыдущих обновлениях будет добавлен НПЦ Лента Новостей, который предоставит следующие услуги:

- Детальная информация о новых и обновленных Зонах Охоты.
- Детальная информация о новых и удаленных квестах.
- Телепортация в новые Зоны Охоты.
- Информация об изменении штрафов за голодных питомцев.
- Позволит закончить удаленные квесты.

## Смотритель Арены

- Добавлены следующие опции Смотрителям Арен и изменена цена на существующие:
    - Восстановление CP / HP - ![ct25p1](../../assets/images/chronicles/ct2_5p1/icon/Адена.jpg) 1,000 аден
    - Положительные эффекты для дуэлей - ![ct25p1](../../assets/images/chronicles/ct2_5p1/icon/Адена.jpg) 2,000 аден
- Изменено размещение Смотрителей Арен на Аренах
    - Смотрители Арены перемещены за пределы PvP зоны

## Система питомцев

- Изменен штраф за проголодавшегося питомца
    - Было: Питомец продолжает получать опыт, питомца можно контролировать, питомец исчезает через некоторое время
    - Стало: Питомец не получает опыт, питомца нельзя контролировать, питомец НИКУДА НЕ ИСЧЕЗНЕТ!
- Стоимость экипировки питомцев уменьшена на 50%
- Стоимость улучшения экипировки питомцев уменьшена на 50%
- Исправлена проблема с пропажей предметов питомцев при использовании склада клана.
- Исправлены предметы для призыва Красных Драконов
- Исправлены иконки предметов для призыва Красных Драконов.

## Благословение Невитта

- Добавлен таймер
    - Можно остановить время действия Благословения Невитта
    - Условия использования таймера - персонаж не охотится на монстров
    - Благословение не действует и не расходуется пока персонаж не в игре.
