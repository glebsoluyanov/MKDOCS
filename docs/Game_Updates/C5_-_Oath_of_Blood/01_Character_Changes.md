# Character Changes

## Maximum Level Increase

The maximum character level has been increased from 78 to 80.

## HP Recovery Speed

The HP recovery speed for characters of all levels has increased.

## Rank System

A character's rank is automatically determined by the character's level, and certain clan rights depend on the character's rank. The rank system is applied to all characters in the game world, regardless of clan membership.

| Rank | Level Range |
|------|------------|
| Vagabond | 1 - 19 |
| Heir | 20 - 39 |
| Knight | 40 - 51 |
| Baron | 52 - 60 |
| Viscount | 61 - 75 |
| Count | 76 - 79 |
| Marquis | 80 |
